# Kit Landing-Page Blue-Suit Hero

Use the attached file **`kit-landing-blue-suit-hero.jpg`** when uploading the separate blue-suit portrait to a Kit landing page. It is a text-free, progressive JPEG at **1920 × 1080 pixels** and approximately **219 KB**. The export preserves the full original composition: the portrait remains on the right and the dark text-safe area remains on the left.

Kit recommends 1920 × 1080 pixels for landscape images. Because Kit adjusts images responsively, use the image as the background or visual block and place any headings or calls to action in Kit’s own text controls rather than inside the photo.[1]
